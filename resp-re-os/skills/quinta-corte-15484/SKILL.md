# QUINTA CORTE — R5 · Lei 15.484 + RG

> A Suprema Corte (R1–R4) não carrega esta lei na cabeça. Esta skill carrega. Sem R5 = sem entrega.

## Checklist R5 (todos obrigatórios)

### A. Forma do tópico (REsp)

- [ ] Existe **tópico específico** com título próprio (não um parágrafo escondido nas razões).
- [ ] O tópico é **fundamentado** — questão federal em uma frase + vetor + dado de transcendência.
- [ ] Se a data do acórdão é ≥ 3.9.2026: tópico é **exigível**. Falta = inadmissão (1.035-A § 3º). REPROVA.
- [ ] Se a data do acórdão é < 3.9.2026: tópico é prudencial. Pode faltar só com nota expressa ao operador. Sem nota = REPROVA.

### B. Presunção

- [ ] Presunção, se houver, é I, II, III, IV ou V do art. 105 § 3º.
- [ ] Inciso VI **não foi preenchido**. Qualquer “outras hipóteses” inventada = REPROVA.
- [ ] Presunção **não omitiu** o tópico. Tópico de presunção demonstra o enquadramento.

### C. Não confundir as vias

- [ ] REsp fala em **relevância** (1.035-A). Não chama isso de repercussão geral.
- [ ] RE fala em **repercussão geral** (1.035). Não cita 1.035-A como se alterasse o RE.
- [ ] Par REsp+RE: duas petições (1.029) e Súmula 126 enfrentada se há fundamento constitucional + infraconstitucional autônomos.

### D. Rito de origem

- [ ] Inadmissão fundada em relevância / RG / repetitivo → via = **agravo interno**, não 1.042.
- [ ] Reclamação 988 V não foi vendida como caminho ordinário.

### E. Vedações de copy

- [ ] Não há “garanto que sobe”, “o STJ vai afetar”, “suspensão nacional automática”.
- [ ] Relator **pode** suspender (§ 7º), não deve. Texto da peça respeita o verbo.

### F. Gap declarado

- [ ] RI do STJ não foi citado como se existisse norma regulamentar publicada.
- [ ] Nenhum acórdão “de aplicação da 15.484” foi inventado.

## Veredito

`R5 LIBERADO` ou `R5 REPROVADO` + lista do item. Reprovado volta à skill de origem. A orquestradora não entrega no meio.

## Guard

Na dúvida entre prudência e lei, declarar os dois estados. Não escolher o mais conveniente para o cliente.
